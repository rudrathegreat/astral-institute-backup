# ASTRAL Website
Official Website for the ASTRAL Institute

## Structure

- `assets/css` - global, page, and tool stylesheets.
- `assets/js` - shared core scripts, components, effects, and page-specific scripts.
- `assets/images`, `assets/icons`, `assets/media` - visual and video assets.
- `assets/docs` - downloadable PDFs and archived document assets.
- `projects` - project case-study pages.
- `tools` - standalone interactive tools.
